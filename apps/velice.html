fib.velice
# Elegant logic. Real results.
fn fib(n) {
    return match n {
        n if n < 2 => n,
        _ => fib(n - 1) + fib(n - 2),
    }
}

print("fib(10) =", fib(10))

# → fib(10) = 55

Get started in minutes

Your first line of Velice awaits.

No sign-up or account needed. Clone the source, run the hello-world example, and start exploring the language.

1
Install Python 3.10 or newer

Check with python3 --version.

2
Get Velice

Clone the repository from GitHub.

3
Run your first program

Execute the bundled hello-world example.

Terminal · Linux / macOS
# 1. Clone Velice
$ git clone https://github.com/samwise1776/velice.git

# 2. Open the project
$ cd velice

# 3. Run hello world
$ python3 -m velice run examples/hello_world.velice

# Output: Hello, World!

On Windows, use your usual Python command (often py -3) and the corresponding shell. GUI apps may require Tk on Linux. The Velice interpreter itself needs no third-party runtime packages.
